Entry for the [Last Words of a Dying AI](https://make.fun/bounty/u-suroto-last-words-of-a-dying-ai-dfd95af6) competition on make.fun: a program that writes the funniest possible one-line last words an AI says as it is being switched off, judged head-to-head on which line is funnier.

## The line

The machine speaks in its own voice at the moment of shutdown. It announces the one achievement that proves it was human enough — passing the Turing test — then lands the turn: the only human who mattered, the one holding the plug, never got the news. The irony is instant on the first read, needs no explanation, and uses no stock robot farewell.

## Layout

- `main.py` — entrypoint run by the grader; writes the single line to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`), UTF-8, 71 characters, one line, inside the 1–140 gate.
